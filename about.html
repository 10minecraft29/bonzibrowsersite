Architecture

Stability first.

BonziBrowser’s current page-rendering design keeps one active native webpage view attached to the main browser window rather than repeatedly changing renderer systems between releases.

Current rendering model: one active WebContentsView for the active tab, attached to the main BrowserWindow. Browser menus use the established overlay/snapshot behavior where needed.
Third-party components

Built on open web technology.

Chromium / Electron

BonziBrowser uses Electron’s Chromium-based web platform for desktop page rendering and browser APIs.

Filter lists

Privacy filtering can use public EasyList/EasyPrivacy/Fanboy list sources. Their terms and attribution remain separate from Bonztel.

Supabase

Bonztel Account features can use Supabase client services with publishable/anon credentials; privileged server secrets do not belong in the desktop client.
