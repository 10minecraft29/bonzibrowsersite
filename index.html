BonziBlock + BonziShield 2.0

Block the noise. Keep the controls.

BonziBlock compiles supported filter syntax into native browser rules. BonziShield adds tracker protection, URL cleanup, HTTPS upgrades and per-site privacy controls.

  • ✓ Block/exception rules, resource types, party/domain restrictions and cosmetic filters
  • ✓ Tracking-parameter cleanup, element picker and local network logger
  • ✓ GPC, DNT, hyperlink-auditing controls and optional strict third-party protection

FAQ

Things you’ll probably want to know.

Is BonziBrowser Chromium-based?

Yes. BonziBrowser uses a Chromium/Electron foundation with a custom Bonztel browser interface and native browser features layered on top.

Is BonziBlock built in?

Yes. The current privacy system is integrated directly into BonziBrowser rather than requiring the standalone BonziBlock + BonziShield extension.

Does BonziBrowser support Chrome extensions?

BonziBrowser supports compatible extension packages and unpacked extensions. Chrome Web Store browsing opens externally, then supported extensions can be installed through BonziBrowser’s extension workflow.

Is Bonztel Sync required?

No. You can use BonziBrowser locally without Sync. A Bonztel Account is used for optional account and synchronization features.

Where does the download come from?

The Windows installer is distributed as a GitHub Release asset. The site’s download buttons point directly to the current 4.1.13 asset.

What if a site breaks with strict privacy controls?

Use the per-site protection controls to relax the relevant setting for that site, then reload it. You can also update filter lists from Privacy & BonziShield.
