Chrome Web Store

Supported Chromium extensions, with review first.

BonziBrowser opens the Chrome Web Store externally for stability. Paste an extension URL or ID into BonziBrowser, then it downloads the official package from Google, unpacks it locally and reviews its requested permissions/APIs before installation.
