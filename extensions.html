Native vs extension

BonziBlock is part of the browser now.

BonziBlock + BonziShield 2.0 is integrated directly into BonziBrowser’s privacy stack in the current build. You do not need to install the standalone blocker extension to get the native protection controls.

Compatible extensions

More than the built-in store.

Unpacked extensions

BonziBrowser can load supported unpacked extensions through its extension manager for development and compatible local packages.

Chrome Web Store workflow

Chrome Web Store detail pages open externally for stability. Copy/paste a supported extension URL or ID into BonziBrowser’s extension installer when needed.

Compatibility scanner

BonziBrowser checks extension packages for compatibility before loading them. Not every Chrome extension API is available in Electron.

Automatic built-in updates

Bundled store extensions are shipped as real resources outside app.asar, allowing BonziBrowser to load and update them normally.
