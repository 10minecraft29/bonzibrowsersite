Release notes

What changed in BonziBrowser.

Feature updates, stability fixes and renderer-preserving patches.

4.1.4
September 5, 2026 · Latest
Current
  • Fixed YouTube player settings/control interaction regressions.
  • Fixed video color/dimming caused by overly broad Bonzi Focus rules.
  • Bonzi Focus 1.1 now avoids all video/player/control ancestors.
  • BonziBlock cosmetic rules are more conservative inside the YouTube player.
  • Expanded built-in Extensions Store with Bonzi Reader, Bonzi Notes and Bonzi Dark.
  • Preserves the known-good single-WebContentsView rendering architecture.
4.1.3
YouTube + extension-store fix
  • Restored stronger YouTube ad protection before filter-list exceptions.
  • Added YouTube player cleanup/skip fallback.
  • Moved bundled extensions to electron-builder extraResources so they load from a real filesystem directory instead of app.asar.
4.1.2
Overlay snapshot fix
  • Menus/popovers use a snapshot-backed overlay so the webpage remains visible behind browser UI overlays.
  • Kept one active WebContentsView instead of replacing the renderer architecture.
4.1.1
Overlay + BonziBlock popover
  • Fixed browser menus being covered by the native page surface.
  • Added a proper BonziBlock/BonziShield hover card with blocked-category breakdown.
4.1.0
BonziBlock + BonziShield 2 integration
  • Stronger filter parser, per-site controls, network logger and privacy dashboard.
  • Expanded EasyList/EasyPrivacy and anti-annoyance support.
