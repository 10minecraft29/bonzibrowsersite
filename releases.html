What changed in BonziBrowser.

Current public release information plus the major privacy, compatibility and UI milestones in the 4.1.x line.

4.1.13
September 5, 2026 · Latest public build
Current
  • Current Windows x64 release distributed through GitHub release tag 3.
  • Includes the current native BonziBlock + BonziShield privacy stack and Bonztel browser feature set.
  • Download filename: BonziBrowser-Setup-4.1.13.exe.
Download 4.1.13GitHub release
4.1.12
Native BonziBlock + BonziShield 2.0 integration
  • Ported the standalone BonziBlock + BonziShield 2.0 compiler and privacy controls directly into BonziBrowser.
  • Added ABP/DNR-style rule matching, cosmetic parsing, custom filters, tracking cleanup, warnings, GPC/DNT, logger and upgraded element picker.
  • Kept a 29,500 + 4,000 compatibility rule budget and the existing one-active-WebContentsView renderer.
4.1.11
Classic YouTube compatibility fix
  • Protected playback-critical YouTube requests from cancellation while preserving the classic request/cosmetic blocker architecture.
  • Collapsed feed/display ad containers and added YouTube-specific compatibility controls without fetch/XHR/player hacks.
4.1.10
Classic BonziBlock rollback
  • Returned BonziBlock to the 4.1.2-style request-cancel + cosmetic-filter approach after experimental YouTube response rewriting proved too invasive.
  • Added safer blocker options around the original method.
4.1.4
YouTube controls + built-in extensions
  • Fixed player settings/control interaction and Bonzi Focus video dimming.
  • Expanded the built-in extension store with Reader, Notes and Dark.
4.1.2
Overlay snapshot fix
  • Added snapshot-backed browser UI overlays so menus can appear over the native page surface without changing renderer architecture.
