How it works

Filtering in BonziBrowser’s request pipeline.

The native integration translates supported ABP/DNR-style conditions into BonziBrowser’s existing Electron request path, then applies cosmetic rules to webpages.

Network filtering

Supports block rules and @@ exceptions, resource types, first/third-party conditions, domain restrictions, $important, $badfilter, literal $removeparam=name, validated regex rules and custom filters.

Cosmetic filtering

Supported ## rules hide unwanted page elements while #@# exceptions allow site-specific un-hiding. Unsupported syntax is skipped rather than guessed.

Filter lists

EasyList, EasyPrivacy, Fanboy Annoyances, EasyList Cookie, Fanboy Social and Fanboy Notifications can be used by the native compiler.

Rule budget

The compatibility budget is 29,500 primary compiled rules plus 4,000 overflow rules, for a 33,500-rule ceiling.

Power tools

Preview selectors, see match counts, move to a parent element and save blocked selectors per site.

Alt+Shift+B opens the picker.

Network logger

Inspect local request decisions when troubleshooting a page. The logger is off by default and remains local to BonziBrowser.

Alt+Shift+L opens the logger.

Playback compatibility

Protection without seeking through your videos.

BonziBrowser’s native blocker does not rely on playback-speed changes, automatic seeking, or Skip Ad button automation. Filtering is performed through the request/cosmetic pipeline. If strict settings break a site, use the per-site controls and reload rather than disabling protection everywhere.
Local vs Sync

What stays on your device.

Local browser data

Browsing data, filter state, custom selectors and the network logger are handled locally unless a feature explicitly offers Sync.

Bonztel Sync

Account-based synchronization is optional. Sync-capable data is tied to your Bonztel Account, while the browser remains usable without signing in.

Publishable Supabase key

Bonztel Account’s client configuration may contain a Supabase publishable/anon key. This is a client credential, not a privileged service-role or database secret.

Filter list updates

When you update filter lists, BonziBrowser retrieves the selected public filter sources and compiles supported rules locally.
