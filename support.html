Troubleshooting

Common questions.

Windows SmartScreen warns about BonziBrowser.

The current build configuration is unsigned. Until you sign the Windows executable with a trusted code-signing certificate, SmartScreen can show an unrecognized-publisher warning.

Chrome Web Store pages open outside BonziBrowser.

This is intentional in the current build because extension-detail pages triggered Electron renderer crashes. BonziBrowser can still install supported Store packages through its Extensions panel.

A site broke after blocking.

Open Privacy & BonziShield, disable BonziBlock/Shield for that site or review the local Network Logger to identify the matching rule.

Where are my browser files?

On Windows, Electron typically stores BonziBrowser data under your AppData\Roaming profile directory. The exact folder name can vary with the packaged product name.

My built-in extension says ENOENT/app.asar.

4.1.3+ packages the extensions-store directory through electron-builder extraResources so bundled extensions live at resources/extensions-store rather than inside app.asar.
